Structural design, argued out by a group of agents.

Describe a structural problem in plain technical prose. A group of AI agents turns it into a validated configuration, runs a 3D topology optimization, looks at the rendered result with a vision model, proposes revisions, re-runs, and scores the candidates against each other — streaming the whole conversation to your browser as it happens.

Launch it →
Runs on a free Colab GPU. About four minutes to start. One API key.

How to run it

  1. Get a free API key.

    Google AI Studio gives one away with no payment method. That is all you need.

  2. Open the notebook and add the key.

    Click the key icon in Colab's left sidebar, add it as GEMINI_API_KEY, and switch on notebook access.

  3. Runtime → Run all.

    One cell. It installs everything and prints a link when the site is ready.

  4. Open the link it prints.

    That is the app. Paste a description, or start from a built-in example.

The agents

pydantic_agent Turns your prose into a validated solver configuration.
to_agent Runs the 3D topology optimization and renders the result.
vllm_agent Looks at the renders and critiques the design.
revise_agent Turns that critique into a revised configuration.
ai_judge Scores the candidates against each other.

Worth knowing

This is research code, and it shows. A run takes minutes, not seconds — the optimization is real, not a canned animation. Results depend on what the agents decide, so two runs of the same description will not be identical. If something breaks, the full notebook exposes every step and doctor.py checks each piece independently.
